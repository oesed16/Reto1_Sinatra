# Retos Sinatra

Soluciones a una serie de retos para practicar los conceptos básicos de [Sinatra](https://sinatrarb.com/), un framework web ligero para Ruby: rutas, parámetros, formularios, vistas `erb`, redirecciones y encabezados HTTP.

Cada carpeta contiene un reto con su descripción (`README.md`) y su solución (`solution.rb`).

## Instalación

Necesitas tener [Ruby](https://www.ruby-lang.org/es/) instalado. Luego instala las gemas:

```bash
gem install sinatra rackup puma
```

Para ejecutar un reto, entra a su carpeta y corre la solución:

```bash
cd Reto1
ruby solution.rb
```

Abre http://localhost:4567 en el navegador.

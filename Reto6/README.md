# Reto 6: Contador

Crea una aplicación en Sinatra que en la ruta `/` muestre un contador que empieza en 0 y un botón **Suma!!**.

- Cada vez que se hace clic en el botón, el contador aumenta en 1.
- Después de sumar, la aplicación debe redirigir de nuevo a `/` mostrando el nuevo valor.

## Cómo ejecutarlo

```bash
gem install sinatra rackup puma
ruby solution.rb
```

Abre http://localhost:4567

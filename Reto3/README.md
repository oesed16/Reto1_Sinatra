# Reto 3: Salúdame

Crea una aplicación en Sinatra que en la ruta `/` muestre un formulario con un campo de texto para escribir un nombre.

- Al enviar el formulario (`POST /saludo`) debe saludar con el nombre escrito, por ejemplo **¡Hola Pedro!**

## Cómo ejecutarlo

```bash
gem install sinatra rackup puma
ruby solution.rb
```

Abre http://localhost:4567

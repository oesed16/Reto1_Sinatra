# Reto 5: Par o impar

Crea una aplicación en Sinatra que en la ruta `/` muestre los números del 1 al 50 e indique si cada uno es par o impar.

- `1 Soy Impar!`
- `2 Soy Par!`
- ...

Usa una vista `erb` con un ciclo.

## Cómo ejecutarlo

```bash
gem install sinatra rackup puma
ruby solution.rb
```

Abre http://localhost:4567

# Reto 7: Abuela sorda

Crea una aplicación en Sinatra que en la ruta `/` muestre un formulario para decirle algo a la abuela.

- Si la frase está escrita toda en MAYÚSCULAS, la abuela responde: **Ahhh si, manzanas!**
- Si no, responde: **Habla más duro mijito**

## Cómo ejecutarlo

```bash
gem install sinatra rackup puma
ruby solution.rb
```

Abre http://localhost:4567
